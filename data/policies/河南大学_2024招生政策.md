# 河南大学 2024年招生政策

> 资料来源：河南大学2024年普通本科招生章程（zs.henu.edu.cn）
> 整理日期：2026-07-30

## 院校简介

- **学校名称**：河南大学（国标代码10475）
- **办学性质**：公办、全日制普通高等学校，国家"双一流"建设高校
- **校区分布**：
  - 郑州龙子湖校区（河南省郑州市郑东新区明理路北段379号）
  - 开封明伦校区（河南省开封市明伦街85号）
  - 开封金明校区（河南省开封市金明大道北段）
- **学科门类**：拥有文、史、哲、经、管、法、理、工、医、农、教育、艺术、交叉学科等13个学科门类的研究型、综合性大学
- **办学层次**：以培养普通本科生、硕士和博士研究生为主，具有学士、硕士、博士学位授予权
- **联办情况**：2024级濮阳工学院、与开封大学联办的本科学生，完成学业后由河南大学颁发毕业证书、学位证书，并标注相应字样

## 录取规则

### 录取体制
我校录取工作在各省（自治区、直辖市）招生委员会或联招办统一组织下进行，按照"学校负责、招办监督"的原则实施录取工作。

### 普通类专业录取原则
1. 以高考成绩为依据，以普通高中学业水平考试成绩和综合素质评价情况为重要参考，实行**"分数优先"**的原则
2. 优先满足高分考生的专业志愿，投档成绩相同时，按照**语文、数学、外语**单科成绩依次排序综合考虑安排专业
3. 考生所报专业志愿无法满足时：
   - 若服从专业调剂，则调剂到我校招生计划尚未完成的非单列计划专业（不区分校区）
   - 若不服从专业调剂，则作退档处理
4. 平行志愿投档录取后，未完成的计划，按照教育部和各省级招生主管部门的规定重新征集志愿
5. 内蒙古自治区考生在招生计划1:1范围内按专业志愿排队录取

### 艺术类专业录取原则
1. 艺术类（含中外合作办学）专业采用考生所在省份对应类别统一考试成绩
2. 考生文化成绩和专业成绩均应达到各省相应批次的最低录取控制分数线
3. 依据"志愿优先"的原则，按照文化成绩和专业成绩各占50%的综合成绩排序，从高分到低分择优录取

### 高考综合改革省份
高考综合改革省份考生选考科目须满足我校招生专业（类）和招生专业组设置的要求。

## 专业录取要求

### 外语语种要求
除外国语言文学类专业外，其他各专业考生入校后的公共外语教学语种为英语，请非英语语种考生谨慎填报。

### 体检要求
专业录取的体检要求，按照教育部、卫生部等部门印发的《普通高等学校招生体检工作指导意见》和有关补充规定执行。

### 预留计划
按照教育部规定，我校将不超过招生计划总数的1%作为预留计划，用于相同分数考生的录取、平行志愿的调节和生源质量的调控。

## 特殊招生政策

招生类型涵盖：
- 普通类专业招生
- 艺术类专业招生
- 体育类专业招生
- **各类专项（定向）招生**（包括国家专项、地方专项等，按教育部和河南省相关规定执行）
- 港澳台地区招生

## 学费标准

依据豫发改收费〔2020〕456号文件执行：

| 专业类别 | 学费标准 |
|---------|---------|
| 文史类 | 4400元/生·年 或 5060元/生·年 |
| 理工类 | 5000元/生·年 或 5750元/生·年 |
| 医学类 | 5500元/生·年 或 6320元/生·年 |
| 艺术类 | 8000元/生·年 |
| 运动训练、武术与民族传统体育专业 | 8000元/生·年 |
| 中外合作办学专业 | 18000元/生·年 |

**学费5060元/生·年的文史类专业**（不含中外合作办学、与开封大学联办相关专业）包括：汉语言文学、新闻学、英语、历史学、行政管理、思想政治教育、经济学、金融学、财政学、会计学、法学、体育教育。

部分优势学科专业学费在基础标准上上浮10%。
