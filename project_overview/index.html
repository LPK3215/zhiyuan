📋 项目简介

智愿（Zhiyuan）是基于 Yuxi（语析） 开源框架构建的高考志愿填报智能咨询系统。它整合了 RAG 检索、Milvus 知识库内知识图谱与 LangGraph 多智能体编排，用户通过类 ChatGPT 的界面与智能体对话，获得带引用来源、知识图谱推理的志愿填报建议。

管理员可配置知识库、模型与权限，管理院校、专业、分数线等数据。系统支持三级权限体系（superadmin / admin / user），提供完整的院校查询、专业搜索、分数线分析和智能咨询功能。

🏗️ 架构全景

智能体请求链路

  1. 前端 AgentView 收集用户输入 → 调用 POST /api/agent/runs
  2. 后端校验用户和智能体 → 创建请求和消息 → 检查 FIFO 队列
  3. 数据库提交成功后 → 向 ARQ 投递 AgentRun
  4. Worker 加载智能体配置 → 执行 LangGraph
  5. 中间件组合：沙盒文件系统、Skills、MCP、SubAgent、知识库
  6. 事件写入 Redis Stream → 前端 SSE 消费
  7. 最终结果写入 PostgreSQL + MinIO

🚀 快速开始

前置要求

  • ✅ Docker + Docker Compose
  • ✅ Node.js 18+ (前端开发)
  • ✅ Python 3.11+ (后端开发)
  • ✅ 兼容 OpenAI 接口的大模型 API

Docker 启动

Bash
# 克隆并初始化
git clone https://github.com/LPK3215/zhiyuan.git
cd zhiyuan
./scripts/init.sh

# 配置环境变量
cp .env.template .env
# 编辑 .env

# 启动（完整模式）
make up

# 或轻量模式
make up-lite

前端：http://localhost:5173 ｜ 后端 API：http://localhost:5050

常用命令

Makefile
make up          # 启动所有服务
make up-lite     # 轻量模式
